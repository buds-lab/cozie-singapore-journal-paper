# Journal figure assets

This folder contains rendered figure assets used by `../cozie_sg.tex`. It contains no raw survey records or participant-level source data.

## Folder structure

- `methods/` — study-design and micro-survey visuals copied from `orenth-usk-data-INTERNAL/2_visualizations/`.
- `data_characterization/` — rendered figures generated from `orenth-usk-data-INTERNAL/5_analysis_spaces/notebooks/01_Data_Characterization.ipynb`.

## Regeneration

The companion notebook [`../notebooks/cozie_singapore_companion.ipynb`](../notebooks/cozie_singapore_companion.ipynb) regenerates the notebook-derived assets in `data_characterization/` **directly under their manuscript filenames** from the public dataset. Run it top to bottom (or `jupyter nbconvert --to notebook --execute --inplace`) and the figures land here, ready for `latexmk -pdf ../cozie_sg.tex`.

Two `data_characterization/` assets are **not** regenerated by the notebook and are retained as committed files: `response_density_and_grid_counts.png` (Figure 3, requires exact home coordinates absent from the public dataset) and `cozie-sankey-organized.png` (Figure 8, a manually reorganized layout of the notebook's `survey_response_flow.pdf`).

`cozie_sg.tex` intentionally retains placeholder captions. Captions, interpretation, and manuscript prose are to be supplied and approved by the authors.
